# Cahier de recette MVP

| Module | Test attendu |
|---|---|
| Auth | Un utilisateur peut s’inscrire, confirmer son e-mail et se connecter. |
| Entreprise | L’utilisateur ne voit que les données de son organisation. |
| Appels d’offres | Création et affichage d’un marché avec échéance. |
| IA DAO | Analyse structurée enregistrée dans la fiche du marché. |
| Mémoire technique | Génération imprimable sans invention de références. |
| Devis | Création d’un devis avec montant TTC et statut. |
| Chantiers | Création d’un chantier, budget et avancement. |
| Facturation | Situation, retenue, TVA, net à payer et règlement. |
| Référentiels | Création d’un client, fournisseur et prix unitaire. |
| Documents | Téléversement dans le bucket privé. |
| Sécurité | Un compte d’une autre entreprise ne peut lire ni modifier les données. |
